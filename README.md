# 租房管理系统 · 纯前端演示

这是一个演示站，没有后端服务器：所有数据都存在**你自己浏览器**的 localStorage 里。
你在页面做的任何新增、修改、删除，只会改变你自己浏览器里的这份数据，
不会影响别人的浏览效果，也不会真的删掉任何东西。

## 测试账号（登录页也能一键填入）

| 角色 | 账号 | 密码 |
| --- | --- | --- |
| 管理员 | admin | admin |
| 屋主 | landlord01 | 123456 |
| 租客 | tenant01 | 123456 |

不同角色看到的菜单和能做的操作不一样：管理员管全局并负责审核，
屋主只能管理自己发布的房源，租客只能下单、预约、评价和收藏。

## 数据乱了怎么办

右上角头像菜单里有「重置演示数据」，点一下就把数据恢复到初始状态
（注意：重置后需要重新登录）。
